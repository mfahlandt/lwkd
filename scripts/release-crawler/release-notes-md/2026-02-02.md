## 🚀 Keep Your Scaffold Updated

The [migration guide](https://master.book.kubebuilder.io/migrations.html) covers upgrading from `any` version to the `latest`, including AI-assisted helpers/commands for legacy scaffolds that may require manual steps. For the smoothest path, enable the [AutoUpdate Plugin (uses GitHub Actions)](https://book.kubebuilder.io/plugins/available/autoupdate-v1-alpha)) or run [`kubebuilder alpha update`](https://book.kubebuilder.io/reference/commands/alpha_update) locally—both use the same update logic. The other options are primarily for older projects missing `cliVersion` in the `PROJECT` file **as a one-time step to reach a supported version**; after that, you can rely on these workflows for ongoing updates.

### (No, really, you MUST read this before you upgrade)

- Action required
  `containerd_discard_unpacked_layers` is now applied only for containerd < 2.1 to avoid warnings with the Transfer Service used in newer versions. (#12821, @guoard)
